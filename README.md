# ⭐ React Quiz App ⭐

## 📝 About
A simple **Quiz App** built with **React**. Shows **one question at a time**, lets users select an answer, calculates the **score**, and allows restarting the quiz. Styled with **CSS** for a clean layout.

---

## 🎯 Features
- 5 multiple-choice questions  
- Shows **one question at a time**  
- **Next button** enabled after selecting an option  
- Displays **final score** at the end  
- **Restart Quiz** button  

### Bonus Features
- Highlights selected option  
- Shows correct/incorrect feedback  

---

## 🛠️ Tech
- React (Functional Components)  
- useState for state  
- CSS for styling  

---

## ⚡ How to Run
```bash
git clone <your-repo-url>
cd react-quiz-app
npm install
npm start
```

---
Open http://localhost:3000 in your browser.
##🔄 How to Use
-Select an answer
-Click Next
-See final score at the end
-Click Restart Quiz to try again
